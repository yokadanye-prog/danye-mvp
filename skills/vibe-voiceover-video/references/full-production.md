# Codex 全片制作、复核和交付

## 接续已选方向

读取 G0/G1 原始确认、正式声音、主时间轴、素材职责、逐句分镜、全片适配、风格、卡片、预算和短片。按既有选择接续，普通实现无需重新询问模式、是否审查或是否渲染。

huashu 主控画面语义、代码复核和主渲染流程，shotcraft 提供准确卡片、demo 和工作台。配方可适配进主工程；保留 TSX 实现时先输出固定画幅、帧率、准确帧数的单镜头片段，再接入主时间轴。中间片段默认静音，原配音作为最终唯一旁白，避免重复音轨与各自计时。

代码、字幕与实际素材引用从同一时间数据生成。随机效果固定种子，状态由时间计算，暂停、跳转和单帧渲染可复现。实现变化更新代码证据和下游检查。

## G2：代码与高风险样段

先用 huashu 镜头表检查和语法规则复核分镜，再检查实现。独立代码审查者对照原任务、声音、分镜及代码只报问题，由制作 Codex 修复。编译通过不能证明任务完成。

每句核对对象、数字、因果、动作、停留与素材。渲开头、最密集段、软件实操、唯一用途素材段和结尾的静帧及短预览。每句都需有动画实现，高风险段需有实际渲出证据。

从实际场景状态或渲染执行导出 `RENDER_MANIFEST.csv` 和 `ASSET_USAGE.csv`，前者列每句帧区间、素材、效果与动作，后者列每件素材的实际可见窗口，允许一句中只展示局部时间。不能手工复制分镜充当运行证据。独立审查核实生成方法与代码。连续可见区间合并计次，消失后重现计新一次；缩略图、蒙版与背景中的引用均计入。

`GATES.json` 记录代码快照、代码审查、样段报告及运行清单的哈希。运行 `check_project.py --gate G2`，问题清零后再完整渲染。工具失败由 Codex 诊断并保留日志，生成启动脚本不能代替实际成片。

## 渲染与声音

原配音决定总时长，同一帧率核准中间片段长度与拼接。音乐和音效按已授权方案在声音锁定后混合、避让旁白；不为拍点重排知识表达。新增付费资源或更换旁白须已有授权。

同一时间轴驱动校对字幕与 SRT。字幕开关关闭文本及底条，校对版和交付版同帧数、同配音时间。截图原生文字保留，网址和敏感内容按约定处理。

## G3：按真实成片放行

独立审查者收到实际 MP4、原任务、配音、分镜、素材职责、动态参考和 G0/G1 选择，只读提交带句 ID、时间码或帧号的问题。制作 Codex 修复、重渲、复核。

- 语义：连续有声审片，或连续分段覆盖全片同步音画。逐句核对对象、数字、动作、因果和素材含义，记录覆盖时段。只有静帧、转录或音轨分析时，语义保持待验。
- 可读：检查对象大小、信息密度、停留、逐句变化、重复动作和结尾，片头通过不能替代正文检查。
- 技术：完整解码、首末帧、分辨率、帧率、时长、峰值、同步、SRT、字幕安全区和净画版本。信号同步不能证明语义正确。
- 展示：按实际成片核对素材时段、次数和裁切，排除网址、账号、二维码与路径，区分示意和实证。
- 自动门禁：按 huashu 规则运行 `qa.py`、`film_gate.py` 和适用字幕区检查，记录原始结果。红灯返回分镜或实现修复，黄灯逐段解释。禁止改阈值、伪造报告或批量扫屏取得放行。

G3 语义、技术、动效报告均绑定当前 MP4 的 SHA256，代码与 G2 快照保持一致。修复后复核受影响内容及接口，旧片报告不能给新片放行。未验证、红灯或阻断问题存在时，候选仅供检查，不能标记最终通过。

运行 `check_project.py --gate G3`，再按 huashu 当前规则运行 `deliver.py`。项目检查器核验记录与哈希，huashu 工具测实际媒体，独立审片验证含义；三者一起构成放行条件。

## 用户参与和文件交付

G0/G1 后普通修复和渲染由 Codex 连续处理。要求实质改变知识、声音、方向、素材职责、费用或交付范围时，说明影响，仅就变化询问。

交付净画 MP4、SRT、原配音、源码、运行引用和审片记录，核对文件存在，给链接、大小和本地位置。按 shotcraft 参考提供动效工作台；需要剪映工程时在当前系统测试兼容性。对外发布须明确授权。
