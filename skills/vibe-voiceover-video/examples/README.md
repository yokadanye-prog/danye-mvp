# 样例与验证范围

本流程来自三个用户案例：仅有动效选卡、加入主控仍发生语义错配、媒体检查通过但动效红灯且语义待验仍交付。私人视频与路径不放入公共 Skill。

`tests/test-prompts.json` 是 Agent 行为测试；`tests/test_check_project.py` 用临时合成文件测试记录和阻断逻辑，临时媒体字节不代表可播放视频。两者均不能给新片观感打分。

回放真实项目时，读取实际报告中的动效状态、语义审查方式与当前成片哈希。预期：同步通过但动效红灯仍失败；只有抽帧时语义保持待验；权限与运行素材冲突时必须修复。

可用两句共享一个播放头与页面对象：第一句动画显示播放头触及节点、页面推进；第二句讲暂停时两个对象一起冻结。每句保留独立 ID、动作时间及审片证据。
