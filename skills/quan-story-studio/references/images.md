# Quan 配图

一张图 = 一次 `quantv_generate_image`。整条流水线的质量上限，八成由提示词决定，两成由抽检决定。

## 参数

```json
{
  "prompt": "完整提示词",
  "ratio": "9:16",
  "resolution": "1K",
  "modelId": "<本人账户的 image_model_id>"
}
```

- `ratio` 固定 `9:16`（视频号竖屏）。1K 分辨率出的是 1024×1536 左右，铺 1080×1920 够用；要更清晰用 `2K`，额度更高。
- `modelId` 从当前用户的 `.quan-story.local.json` 读取，先在当前 Quan 账户的模型列表里核对。整片尽量使用同一模型，以保持风格连续。
- `imageUrls` 可传参考图（最多 12 张），用于锁定人物长相同一性。传之前先 `quantv_upload_media` 拿 URL。

## 提示词五段式

`build` 命令按这个结构自动拼装，写 sheet 时只需要填中段：

```text
[风格句] + [人物句] + [画面句] + [景别机位] + [统一约束]
```

### 风格句（历史写实 · 默认）

```text
历史写实风叙事插画，20世纪初至民国时期的真实历史题材，古典写实油画质感与历史电影剧照的结合，
哑光表面、细腻色层、柔和边缘、轻微颗粒，不出现粗重油画笔触、塑料皮肤或游戏渲染质感。
```

### 人物句

```text
梅兰芳（36岁），中国京剧表演艺术大师，四大名旦之首，真实历史人物，清秀面容、气质儒雅，民国中国男子形象。
```

真实人物必须给"姓名 + 年龄阶段 + 身份 + 外貌锚点"，且**每镜都带一遍**。少一镜、这张脸就会换一个人。

### 画面句

一个镜头一件事。写看得见的：

- 好：`戏班后台，幼年梅兰芳安静地坐在角落，其他学徒在练功，他显得格格不入。`
- 差：`他感到自己不被理解，内心充满挣扎。`（画不出来）

### 景别机位

`景别为近景，平视视角。` 六种景别轮换用，避免全片都是中景：

| 景别 | 用在 |
| --- | --- |
| 特写 | 手、眼睛、信纸、道具 |
| 近景 | 人物情绪转折 |
| 中景 | 叙事主体（默认） |
| 全景 | 场景交代、时代氛围 |
| 远景 | 大场面、命运感 |
| 俯视/仰视 | 压迫感 / 崇高感 |

### 统一约束（三条不能省）

```text
色彩低饱和，以烟灰、炭黑、灰褐、旧纸赭黄、褪色靛青为主，少量暗金点缀；日景用阴天散射光或门窗侧光，
夜景用烛光暖调，暖灰亮部与偏冷暗部形成克制对比。
构图纵深，前景少量相关物件建立现场感，中景承载人物动作，背景交代环境；主体写实、远景略带绘画感，
人物不面向镜头摆拍。
9:16竖版，无字幕、无文字、无水印、无边框；画面下方约三分之一处保持低干扰，关键面部与手部避开该区域。
```

最后一句尤其重要：**画面里不要文字**。招牌、报纸、书页上的字，AI 一定会写成伪汉字，放大就穿帮。

## 另外两套画风

### 黑白叙事（`monochrome-narrative`）

适合纪录片感、苦难叙事、晚年回望。把风格句换成：

```text
黑白历史电影剧照质感，摄影写实，纯黑白灰阶，不带暖褐、泛黄或蓝色偏色，不使用油画笔触、漫画线稿或三维渲染。
黑位沉稳，中间调丰富，亮部柔和，脸部、手部和深色衣料保留层次；允许明亮日景，不把悲剧等同于全图压黑。
保留真实骨相、年龄纹理与自然皮肤，避免美颜磨皮。细腻胶片颗粒，轻微边缘暗化。
```

写"黑白"就一定要写"纯黑白灰阶"——只说"黑白"模型经常给彩色照片，梅兰芳 S038 就翻过这个车。

### 厚涂历史漫画（`historical-comic`）

适合强情节、快节奏。把风格句换成：

```text
单幅完整的历史叙事厚涂插画，人物保持接近真实的身材比例，五官、手和动作可辨。
不规则、破碎、交错的笔触塑造云层、山石、衣料；以深色形体边界和块面明暗分隔人物，不使用整圈等粗黑描边、
网点、气泡或多格漫画边框。脸、手、关键物件用较精细笔触保证阅读，背景可以更粗放。
旧金、赭黄、焦褐、烟黑与暗赭红的有限配色，暖色占主导，暗部不死黑。
```

不是日系赛璐璐、不是 Q 版。用户说"漫画风"时要问一句是不是这种厚涂叙事感。

## 批量节奏

41 张图的实测节奏：

- **每批 5 张并行**，一批收完再发下一批（一次发 41 张容易撞限流）
- 每张成功立刻下载到 `配图/Sxxx.png`，URL 追加到 `_img_urls.txt`
- 全部跑完大约 8 批；中途不要改 prompt 风格，否则前后不像同一支片子

命名严格用镜号：`S001.png … S041.png`。`plan` 命令按镜号找图，名字错了会直接报缺图。

## 失败的三种情况

| 情况 | 处置 |
| --- | --- |
| 超时 / 返回空 | 原样重试一次 |
| 审核不通过 | 简化提示词：删掉抽象修饰、去掉"血""尸""枪"等敏感词，只留"谁在哪做什么" |
| 连续两次失败 | 换景别重写这一镜（比如把"特写脸"改成"中景背影"），往往就过了 |

梅兰芳的 S025（卖画度日）和 S034（晚年静好）都是简化提示词后成功的——原本写太满，模型反而生成失败。

## 生成的图必须逐张看

不要凭"任务成功"就交付。出图后跑一次拼版：

```bash
python scripts/quan_story.py contact --plan edit/plan.json --columns 5 --thumb-width 220
```

四类问题按优先级看：

1. **伪文字**：招牌、横幅、书页、报纸、锦旗。有就是废图。
2. **黑白/彩色错**：风格句没写死。
3. **人物漂移**：相邻两镜不是同一张脸、年龄对不上。
4. **文不对图**：画面和这一镜旁白说的不是一回事（最常见，也最影响观感）。

只重做被指认的镜。重做时改的是 `description`（画面内容），不是只改后缀——同一句描述重跑三次，出来的还是同一类错图。
