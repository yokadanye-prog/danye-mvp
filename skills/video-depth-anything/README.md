# Video Depth Anything 配套 Skill

将已有本地视频提取为相对灰度深度参考。完整 Skill 文件随套件提供，模型程序、Python 环境和权重另装。

先按 [环境安装指南](references/installation.md) 准备运行条件，再使用 [SKILL.md](SKILL.md)。分享版通过 ToolRoot／PythonPath 或用户环境变量定位运行环境，示例路径需要替换。

此目录是主视频复刻工作流的配套技能。仅执行深度提取和检查；成片生成使用用户自己的其他工具，并遵守主流程的付费确认要求。

本地适配脚本和指令许可见 [LICENSE](LICENSE)。上游推理项目与模型权重遵守其各自授权，来源为 [Video Depth Anything](https://github.com/DepthAnything/Video-Depth-Anything)。该目录不附带上游程序与权重。
